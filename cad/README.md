# CAD Exports & OnShape Assemblies

Store exported `.step` and `.stl` files from OnShape here, organized by module and revision.

Refer to [`../docs/cad_spec.md`](../docs/cad_spec.md) for:
- Global OnShape parametric variables (`#card_w`, `#card_l`, `#slot_pitch`, etc.)
- Nozzle/clearance guidelines for PLA/PETG
- Exact dimensions for all 5 mechanical modules
- Bench-test print order (start with **Bench Test A: Expanding-Comb Drop Chute** and **Bench Test B: Single-Card Feeder**)

## Suggested Folder Convention

```text
cad/
├── bench_test_a_comb_drop/
├── bench_test_b_feeder/
├── module_2_scan_tunnel/
├── module_3_elevator/
└── module_5_enclosure/
```
